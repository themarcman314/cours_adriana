Je veux que tu m'implémentes les 3 fonctions suivantes:

1. Une fonction appelée `somme` prenant deux entiers, appelés `val1` et `val2`, qui retourne un la somme des deux sous forme d'un entier.

2. Une fonction appelée `soustraction` prenant deux entiers signés de 8 bits (`val1`, `val2`) retournant un entier signé sur 8 bits aussi.
Cette fonction effectue la soustraction entre les deux entiers passés en paramètre.

3. Une fonction appelée `inutile` retournant rien, prenant deux flottants double précision: que l'on choisit d'appeler `truc` et `bidule`.
Cette fonction multipliera simplement les paramètres entre eux.


Je veux que tu m'appelles les 3 fonctions dans une fonction main (tu pourras imprimer les résultats avec `printf` pour vérifier le résultat).
